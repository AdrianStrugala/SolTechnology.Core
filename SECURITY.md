# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 2.x | Yes |
| 1.x and older | No; upgrade to 2.x |

Security fixes ship as a new 2.x patch release of the affected `SolTechnology.Core.*` packages.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability** (GitHub Private Vulnerability Reporting). If that button is not shown,
email [contact@soltechnology.dev](mailto:contact@soltechnology.dev) with "SolTechnology.Core
security" in the subject.

Include the affected package and version, a description of the issue, and steps or code that
reproduce it. The maintainer aims to answer within seven days. Once a fix is released, the advisory is
published and you are credited unless you ask otherwise.
