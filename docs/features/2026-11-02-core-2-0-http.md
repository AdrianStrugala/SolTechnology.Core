# SolTechnology.Core 2.0 — HTTP

> Historical delivery record. It may not describe the current system.

## Goal

Deliver the 2.0 hardening of `SolTechnology.Core.HTTP` end-to-end, as one library of the SolTechnology.Core 2.0
flagship release. Success means:

- POST and PATCH are never retried after an exception or timeout (`S3`, P-10).
- The request pipeline, the upstream health check, and options validation are correct (`http-api#5`, `#6`, `#8`, `#9`, `#15`–`#17`, L-02).
- `HttpClientExtensions` lives in `SolTechnology.Core.HTTP`, the upstream health check uses `IHttpClientFactory`, and `RequestBuilder` verbs drop the `Async` suffix (`C-10`…`C-12`).
- HTTP ships XML docs, `docs/Clients.md` and `docs/HTTP-Production-Checklist.md` that compile against 2.0, conforms to the Coding Guide, and logs with `[{Placeholder}]` templates.
