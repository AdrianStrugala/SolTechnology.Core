# SolTechnology.Core 2.0 — Cache

> Historical delivery record. It may not describe the current system.

## Goal

Deliver the 2.0 hardening of `SolTechnology.Core.Cache` end-to-end, as one library of the SolTechnology.Core 2.0
flagship release. Success means:

- The local cache evicts faulted entries, runs one factory per key (single flight), and the local lock is correct.
- Keys are namespaced by `TKey`/`TItem` without assembly versions, `DistributedCacheConfiguration.InstanceName` has no default and is validated non-empty at start, and options are validated (P-07, RM-2, RM-3).
- Lock and idempotency contracts drop the `Async` suffix (`C-13`).
- Cache ships XML docs, a `docs/Cache.md` README that compiles against 2.0, conforms to the Coding Guide, and logs with `[{Placeholder}]` templates.
