# SolTechnology.Core 2.0 — AUID

> Historical delivery record. It may not describe the current system.

## Goal

Deliver the 2.0 hardening of `SolTechnology.Core.AUID` end-to-end, as one library of the SolTechnology.Core 2.0
flagship release. Success means:

- `Auid` formats culture-invariantly, `TryParse` range-checks every part, and the overflow message is English (`B10`, `B11`).
- The JSON and type converters follow the framework contracts (P-08), and the docs state the real uniqueness bound and ordering.
- `Auid` and its converters live in `SolTechnology.Core.AUID`; the static `Auid.TimeProvider` is replaced by `TimeProvider` overloads (`C-08`, `C-09`).
- AUID ships XML docs, a `docs/AUID.md` README that compiles against 2.0, and conforms to the Coding Guide.
